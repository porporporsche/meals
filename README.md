# ごはん帳

食事を記録して、カロリーと栄養バランスを見える化する Web アプリです。スマホで撮った写真から、Claude が料理と量を読み取り、栄養を推定します。

- **写真から記録**：カメラで撮る、またはアルバムから選ぶ（1食につき最大4枚）
- **料理名から記録**：「カツ丼 並盛、味噌汁」のように入力
- **手入力**：APIキーがなくても使えます
- **見える化**：カロリー、PFC、食物繊維、塩分を目標値と比較。7日間の推移グラフ
- **アドバイス**：その日の評価、次の食事のおすすめ、1週間の傾向

サーバーは不要です。GitHub Pages に置くだけで動きます。

## GitHub Pages での公開手順

1. GitHub で新しいリポジトリを作ります（例：`gohan-cho`）。
2. このフォルダのファイルをすべてリポジトリ直下に置いて push します。
   - `index.html` / `manifest.webmanifest` / `sw.js` / `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` / `.nojekyll`
   - `.nojekyll` は隠しファイルです。zip を展開したときに見えなくても、そのまま一緒にアップロードしてください。
3. リポジトリの **Settings → Pages** を開き、**Source** を「Deploy from a branch」、**Branch** を `main`・`/ (root)` にして保存します。
4. 1〜2分待つと `https://<ユーザー名>.github.io/gohan-cho/` で開けます。

## スマホでの使い方

1. 上の URL をスマホのブラウザで開きます。
2. ホーム画面に追加すると、アプリのように使えます。
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：メニュー →「ホーム画面に追加」
3. ページ下の **「APIキーとモデル」** に Anthropic API キーを入れて「保存して接続テスト」を押します。
   - キーは [Anthropic Console](https://console.anthropic.com/settings/keys) で発行します。
4. **「からだと目標の設定」** に性別・年齢・身長・体重・活動量・目標を入れると、1日の目標値が計算されます。
5. 「食事を記録」→「カメラで撮る」で写真を撮り、「写真を解析」を押します。推定結果を確認・修正して記録します。

## データと API キーの扱い

- 記録・設定・API キーは、**使っている端末のブラウザの中だけ**に保存されます。GitHub やほかのサーバーには保存されません。リポジトリが公開でも、他人に記録やキーが見られることはありません。
- 写真は縮小してから Anthropic API に直接送られます。記録には小さなサムネイルだけを残します。
- 端末やブラウザごとに記録は別になります。機種変更の前には「データのバックアップ」で JSON を書き出して、新しい端末で読み込んでください。スマホでは共有メニューが開くので、「ファイルに保存」や Google ドライブを選びます。
- **iPhone の注意**：Safari で開いたページと、ホーム画面に追加したアプリでは、記録が別々に保存されます。また Safari では、長く開かないとサイトのデータが消されることがあります。**ホーム画面に追加して、そちらで使い続ける**のがおすすめです。
- 撮影中にブラウザが再読み込みされても（Android で起きやすい）、選んだ写真と確認中の内容は残ります。
- 一度開けば、電波がなくてもアプリは開けます（手入力・グラフ・目標の確認ができます）。写真の解析とアドバイスには通信が必要です。
- API キーはブラウザに保存されるため、共用の端末では使わないでください。念のため Console で**利用上限額**を設定しておくことをおすすめします。

## 料金の目安

写真の解析やアドバイスでは、Anthropic API の従量料金がかかります。料金を抑えたいときは、設定でモデルを「Haiku」に変えてください。

## 注意

栄養値は推定を含む目安です。持病や食事制限がある場合は、医師や管理栄養士の指示を優先してください。
